# LEGOS — Las 24 Combinaciones de Variaciones

Este documento define en profundidad las 24 combinaciones LEGO que Frank puede ejecutar. Cada LEGO especifica qué bloques cambian, qué se conserva, qué hace Frank exactamente y cuándo tiene sentido usarlo para escalar un anuncio winner.

Para entender qué hace cada bloque individualmente → ver `references/categorias.md`
Para entender cómo adaptar cada formato → ver `references/formatos.md`

---

## CÓMO LEER CADA LEGO

Cada LEGO tiene:
- **Qué cambia y qué se conserva** — los bloques en negrita son los que cambian
- **Qué hace Frank** — si reescribe, describe o ambos
- **Lógica del cambio** — por qué esta combinación tiene sentido
- **Cuándo usarlo** — en qué momento del ciclo de vida del anuncio es más útil

---

## LEGO 1 — Clonación Total

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** Nada. Todo se toma de la referencia.
**Qué hace Frank:** Confirma que el usuario quiere replicar el anuncio exactamente como está y entrega el guión original limpio en 3 bloques para facilitar la producción.

**Lógica:** Antes de hacer cualquier variación, primero se clona el winner para tener una línea base de comparación. Todo lo que venga después se mide contra esta versión.

**Cuándo usarlo:** Como punto de partida antes de comenzar a testear variaciones. También cuando se quiere lanzar el mismo anuncio en un nuevo mercado geográfico sin cambiar nada.

---

## LEGO 2 — Material Nuevo

**Bloques:** 📦 **Material nuevo** + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** Los clips donde aparece el producto.
**Qué hace Frank:** Conserva el script completo. Describe qué nuevas tomas grabar del producto: ángulos, escenarios, personas, luz y momentos del guión donde va cada clip.

**Lógica:** El script ya probó que convierte. La pregunta es: ¿el producto se ve mejor desde otro ángulo o en otro contexto? Esta variación responde esa pregunta sin tocar lo que ya funciona.

**Cuándo usarlo:** Cuando se tiene acceso para grabar nuevas tomas del producto. Cuando el material original es de baja calidad o fue filmado rápido para testear. Cuando se quiere mostrar el producto en un escenario diferente (uso en iglesia vs uso en casa).

---

## LEGO 3 — Stock Nuevo

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 **Stock nuevo** + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** Todos los clips de apoyo visual que no son del producto ni del avatar.
**Qué hace Frank:** Conserva el script completo. Para cada momento del guión que usa stock, describe qué clip nuevo buscar, en qué banco de imágenes y qué términos de búsqueda usar.

**Lógica:** Es la variación de menor costo y mayor velocidad. No requiere grabar nada — solo reemplazar clips en la edición. Puede hacer que el mismo anuncio se vea completamente diferente visualmente.

**Cuándo usarlo:** Como primera variación antes de invertir en nueva producción. Cuando el stock original ya está sobreusado en el nicho. Cuando se quiere adaptar el contexto visual a otro mercado regional sin cambiar el guión.

---

## LEGO 4 — Música Nueva

**Bloques:** 📦 Material + 📝 Script + 🎵 **Música nueva** + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** La pista de música de fondo.
**Qué hace Frank:** Conserva el script completo. Describe el género, mood, tempo e instrumentos de la nueva pista. Sugiere términos de búsqueda en bibliotecas de música libre de derechos.

**Lógica:** La música afecta el estado emocional del espectador. Dos anuncios con el mismo guión pero música diferente pueden generar sensaciones distintas. Esta variación testea si otra pista del mismo mood mejora la retención.

**Cuándo usarlo:** Cuando la música original tiene derechos de autor y no se puede usar en pauta. Cuando se quiere testear si una pista diferente dentro del mismo género genera más engagement. Cuando la música original ya está muy asociada a otra marca del mismo nicho.

---

## LEGO 5 — Hook Nuevo

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 **Hook nuevo** + 🎯 CTA + 📐 Formato
**Qué cambia:** Solo el gancho de apertura (primeros 3-7 segundos).
**Qué hace Frank:** Conserva el cuerpo y el CTA exactamente. Redacta un nuevo hook usando un ángulo diferente al original o el mismo ángulo con una entrada más potente. Aplica la palanca de "más curioso".

**Lógica:** El hook es el filtro de entrada. Si el cuerpo convierte pero el CTR es bajo, el problema está en el hook. Esta variación testea si otro gancho atrae más atención sin tocar lo que ya convierte en el cuerpo.

**Cuándo usarlo:** Cuando el anuncio tiene buen costo por resultado pero bajo CTR o baja retención en los primeros 3 segundos. Cuando se quiere testear múltiples ganchos con el mismo cuerpo para identificar cuál engancha mejor al avatar.

**Nota de ejecución:** Frank redacta mínimo 2 versiones de hook con ángulos diferentes para que el usuario elija o teste ambos.

---

## LEGO 6 — CTA Nuevo

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 **CTA nuevo** + 📐 Formato
**Qué cambia:** Solo el cierre del anuncio.
**Qué hace Frank:** Conserva el hook y el cuerpo exactamente. Redacta un nuevo CTA con un objetivo persuasivo diferente al original. Elige el objetivo más adecuado según el contexto del producto y el momento de la campaña.

**Lógica:** Si el anuncio tiene buena retención pero baja conversión final, el problema está en el CTA. Esta variación testea si otro tipo de cierre mejora la tasa de acción sin cambiar el resto.

**Objetivos de CTA disponibles:** urgencia / escasez / regalo extra / anticipación / curiosidad / prueba social

**Cuándo usarlo:** Cuando el anuncio tiene buena retención y buen CTR pero bajo porcentaje de conversión en WhatsApp o landing. Cuando se quiere testear estacionalidad (CTA de urgencia en lanzamiento, CTA de prueba social cuando ya hay testimonios).

---

## LEGO 7 — Formato Nuevo

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 **Formato nuevo**
**Qué cambia:** El estilo de presentación y narración del anuncio.
**Qué hace Frank:** Mantiene la estructura invisible y el ángulo ganador intactos. Adapta todo el script al nuevo formato elegido. Entrega en 3 bloques con el guión reescrito en el lenguaje y dinámica del nuevo formato.

**Lógica:** El mismo mensaje puede conectar de formas muy diferentes según cómo se empaca. Un testimonio directo a cámara y un formato podcast dicen lo mismo pero generan experiencias distintas en el espectador. Esta variación testea el empaque sin cambiar el contenido.

**Formatos disponibles:** POV / Selfie / Pantalla Verde / Entrevista / Podcast / Conferencia / Skin Care / Pregunta
→ Ver `references/formatos.md` para la descripción y criterios de cada formato.

**Cuándo usarlo:** Cuando el anuncio tiene buen rendimiento pero se quiere escalar a nuevos públicos que consumen contenido en formatos diferentes. Cuando el formato original ya está sobreexpuesto en el nicho y el avatar lo identifica como "anuncio" antes de verlo.

---

## LEGO 8 — Hook + CTA Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 **Hook nuevo** + 🎯 **CTA nuevo** + 📐 Formato
**Qué cambia:** La apertura y el cierre. El cuerpo se conserva exactamente.
**Qué hace Frank:** Redacta un nuevo hook y un nuevo CTA. El cuerpo permanece idéntico al winner original.

**Lógica:** Si el cuerpo es sólido y el anuncio convierte, esta combinación permite testear múltiples entradas y cierres sin tocar lo que ya demostró funcionar. Es la variación más quirúrgica para optimizar el embudo del anuncio.

**Cuándo usarlo:** Cuando se tiene certeza de que el cuerpo convierte (hay datos de retención o testimonios que lo confirman) pero se quiere mejorar el CTR inicial y la conversión final simultáneamente. También útil para refrescar un anuncio que está en fatiga sin regrabar todo.

---

## LEGO 9 — Stock + Música Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 **Música nueva** + 🎬 **Stock nuevo** + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** Todo el fondo visual (stock) y el fondo sonoro (música).
**Qué hace Frank:** Conserva el script completo. Describe el nuevo stock para cada momento del guión y especifica el perfil de la nueva pista musical.

**Lógica:** Cambiar stock y música simultáneamente transforma la experiencia audiovisual completa del anuncio sin necesidad de grabar nada nuevo. El espectador lo percibe como un anuncio diferente aunque el guión sea idéntico.

**Cuándo usarlo:** Cuando el anuncio está en fatiga visual (el público ya lo reconoce) pero el guión sigue convirtiendo. Es la variación de mayor impacto visual con el menor costo de producción.

---

## LEGO 10 — Material + Formato Nuevos

**Bloques:** 📦 **Material nuevo** + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 **Formato nuevo**
**Qué cambia:** Las tomas del producto y el estilo de narración.
**Qué hace Frank:** Adapta el script al nuevo formato manteniendo la estructura invisible. Describe qué nuevas tomas del producto grabar y cómo integrarlas al nuevo formato.

**Lógica:** Combina un empaque narrativo diferente con material visual nuevo del producto. El resultado es un anuncio que se siente completamente renovado tanto en cómo se cuenta como en cómo se muestra el producto.

**Cuándo usarlo:** Cuando se quiere hacer una renovación significativa del anuncio sin cambiar el guión base. Ideal cuando hay disponibilidad de grabar nuevo material del producto y se quiere aprovechar para cambiar el formato al mismo tiempo.

---

## LEGO 11 — Hook + Formato Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 **Hook nuevo** + 🎯 CTA + 📐 **Formato nuevo**
**Qué cambia:** El gancho de apertura y el estilo de narración.
**Qué hace Frank:** Redacta un nuevo hook adaptado al nuevo formato. Adapta el cuerpo y el CTA al nuevo formato manteniendo la estructura invisible. Entrega en 3 bloques.

**Lógica:** El formato define cómo se narra — y cada formato tiene un tipo de hook más natural. Un podcast abre diferente a un selfie. Esta combinación asegura que el gancho y el empaque estén perfectamente alineados.

**Cuándo usarlo:** Cuando se quiere probar un formato diferente y al mismo tiempo optimizar el hook para que sea coherente con ese nuevo estilo de narración. Más efectivo que cambiar solo el formato sin ajustar el hook.

---

## LEGO 12 — Stock + Formato Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 **Stock nuevo** + 🪝 Hook + 🎯 CTA + 📐 **Formato nuevo**
**Qué cambia:** Los clips de apoyo visual y el estilo de narración.
**Qué hace Frank:** Adapta el script al nuevo formato. Describe el nuevo stock coherente con el formato elegido.

**Lógica:** Cada formato tiene un tipo de stock que le es natural. Un formato podcast usa imágenes de conversación; un formato conferencia usa gráficos y apoyos visuales. Esta combinación asegura que el stock refuerce el formato elegido.

**Cuándo usarlo:** Cuando se quiere cambiar el empaque del anuncio y al mismo tiempo actualizar el apoyo visual para que sea coherente con el nuevo formato. Sin necesidad de grabar material nuevo del producto.

---

## LEGO 13 — Material + Stock + Música Nuevos

**Bloques:** 📦 **Material nuevo** + 📝 Script + 🎵 **Música nueva** + 🎬 **Stock nuevo** + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** Todo lo visual y sonoro. El script se conserva exactamente.
**Qué hace Frank:** Conserva el guión completo. Describe los nuevos clips de producto, el nuevo stock para cada momento del guión y el perfil de la nueva pista musical.

**Lógica:** Es la renovación audiovisual total de un anuncio sin tocar una sola palabra del guión. El resultado es un anuncio que se ve y suena completamente diferente pero dice exactamente lo mismo.

**Cuándo usarlo:** Cuando el guión tiene resultados probados y no se quiere arriesgar cambiando el copy. Cuando el anuncio está en fatiga visual severa. Cuando se tiene presupuesto de producción para grabar nuevo material y se quiere aprovechar al máximo.

---

## LEGO 14 — Todo Nuevo Menos Script (Cuerpo)

**Bloques:** 📦 **Material nuevo** + 📝 Script + 🎵 **Música nueva** + 🎬 **Stock nuevo** + 🪝 **Hook nuevo** + 🎯 **CTA nuevo** + 📐 **Formato nuevo**
**Qué cambia:** Todo excepto el cuerpo del script.
**Qué hace Frank:** Redacta nuevo hook y nuevo CTA. Adapta ambos al nuevo formato elegido. Describe los cambios de material, stock y música. El cuerpo permanece idéntico.

**Lógica:** El cuerpo es el corazón del anuncio — donde está la argumentación, el mecanismo y la demostración. Si el cuerpo convierte, se protege y se renueva todo lo que lo rodea para darle nueva vida al anuncio completo.

**Cuándo usarlo:** Cuando hay evidencia clara de que el cuerpo del anuncio es lo que convierte (testimonios, datos de retención en la sección media del video) y se quiere renovar completamente la experiencia audiovisual sin arriesgar ese núcleo.

---

## LEGO 15 — Script + Formato Nuevos

**Bloques:** 📦 Material + 📝 **Script nuevo** + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 **Formato nuevo**
**Qué cambia:** El guión completo y el estilo de narración.
**Qué hace Frank:** Reescribe todo el guión (Hook-Cuerpo-CTA) usando la misma estructura invisible y ángulo ganador. Adapta el nuevo guión al formato elegido. Entrega en 3 bloques.

**Lógica:** Combinar nuevo guión con nuevo formato produce un anuncio que se siente completamente diferente al winner original tanto en contenido verbal como en empaque visual. Es la variación más profunda dentro del sistema LEGO sin cambiar el ángulo ganador.

**Cuándo usarlo:** Cuando se quiere una renovación profunda del anuncio pero sin grabar nuevo material del producto. Cuando el formato original ya está sobreexpuesto y el guión también necesita palabras nuevas.

---

## LEGO 16 — Script Nuevo

**Bloques:** 📦 Material + 📝 **Script nuevo** + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** El guión completo con otras palabras y situaciones.
**Qué hace Frank:** Reescribe todo el guión (Hook-Cuerpo-CTA) con la misma estructura invisible y ángulo ganador. Nuevas palabras, nuevas situaciones cotidianas, nuevas frases atómicas — misma lógica narrativa.

**Lógica:** Es la variación de redacción más pura. El ángulo ganador demostró funcionar — la pregunta es si las mismas ideas expresadas con otras palabras convierten igual o mejor.

**Cuándo usarlo:** Cuando se quiere testear si otras palabras mejoran la conversión sin cambiar nada más. Cuando el anuncio está en fatiga de copy (el avatar ya lo tiene memorizado). Como segunda versión del winner para tener siempre dos guiones activos en rotación.

---

## LEGO 17 — Script + Stock Nuevos

**Bloques:** 📦 Material + 📝 **Script nuevo** + 🎵 Música + 🎬 **Stock nuevo** + 🪝 Hook + 🎯 CTA + 📐 Formato
**Qué cambia:** El guión completo y los clips de apoyo visual.
**Qué hace Frank:** Reescribe el guión completo. Describe el nuevo stock para cada momento del nuevo guión — asegurando que el apoyo visual sea coherente con las nuevas palabras.

**Lógica:** Cuando se cambia el script, el stock original deja de tener sincronía narrativa con el nuevo guión. Esta combinación asegura que el apoyo visual esté alineado con las nuevas ideas expresadas.

**Cuándo usarlo:** Siempre que se reescriba el guión y el stock original haga referencia explícita a situaciones o palabras que cambiaron. Es la versión responsable del Script Nuevo — no dejar el stock desconectado del nuevo copy.

---

## LEGO 18 — Hook + Stock Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 **Stock nuevo** + 🪝 **Hook nuevo** + 🎯 CTA + 📐 Formato
**Qué cambia:** El gancho de apertura y los clips de apoyo visual.
**Qué hace Frank:** Redacta un nuevo hook. Describe nuevo stock coherente con ese hook y con el resto del cuerpo. El cuerpo y el CTA se conservan.

**Lógica:** El hook visual y el stock de los primeros segundos son lo primero que el avatar procesa. Renovar ambos refresca la entrada del anuncio de forma completa — verbal y visualmente — sin tocar el cuerpo que convierte.

**Cuándo usarlo:** Cuando el anuncio tiene buen rendimiento en el cuerpo pero la entrada visual ya es reconocida por el público y genera la respuesta automática de "esto es un anuncio". Renovar el hook y el stock de entrada rompe ese reconocimiento.

---

## LEGO 19 — Avatar IA Nuevo

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 Formato + 👤 **Avatar IA nuevo**
**Qué cambia:** El personaje que narra el guión.
**Qué hace Frank:** Conserva el script completo. Describe el perfil del nuevo narrador: género, edad aproximada, esencia, tonalidad, herramienta de IA sugerida y tipo de fondo que debe acompañarlo.

**Lógica:** El mismo guión narrado por un rostro diferente puede conectar de forma distinta con el avatar. Esta variación testea si otro perfil visual del narrador mejora la identificación del espectador con el anuncio.

**Cuándo usarlo:** Para testear qué perfil de narrador genera más confianza en el avatar específico del anuncio. Cuando el avatar IA original ya está sobreexpuesto en otros anuncios del nicho. Cuando se quiere adaptar el anuncio a otro mercado regional con un perfil más cercano a ese público.

---

## LEGO 20 — Avatar IA + Hook Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 **Hook nuevo** + 🎯 CTA + 📐 Formato + 👤 **Avatar IA nuevo**
**Qué cambia:** El narrador y el gancho de apertura.
**Qué hace Frank:** Redacta un nuevo hook. Describe el perfil del nuevo narrador. El cuerpo y el CTA se conservan.

**Lógica:** El hook es lo primero que el avatar ve y escucha. Si al mismo tiempo se cambia el rostro del narrador, la entrada del anuncio se renueva completamente — el avatar no lo reconoce como el mismo anuncio en los primeros 3 segundos.

**Cuándo usarlo:** Para testear apertura y narrador simultáneamente. Más eficiente que dos variaciones separadas cuando se quiere entender si la mejora viene del hook, del narrador o de la combinación de ambos.

---

## LEGO 21 — Avatar IA + Formato Nuevos

**Bloques:** 📦 Material + 📝 Script + 🎵 Música + 🎬 Stock + 🪝 Hook + 🎯 CTA + 📐 **Formato nuevo** + 👤 **Avatar IA nuevo**
**Qué cambia:** El narrador y el estilo de presentación.
**Qué hace Frank:** Adapta el script al nuevo formato. Describe el perfil del nuevo narrador coherente con ese formato. Entrega en 3 bloques.

**Lógica:** Cada formato tiene un tipo de narrador que le es natural. Un podcast tiene un narrador conversacional; un formato selfie tiene un narrador espontáneo y cercano. Esta combinación asegura que el nuevo narrador y el nuevo formato estén perfectamente alineados.

**Cuándo usarlo:** Cuando se quiere cambiar el empaque completo del anuncio — cómo se ve y quién lo dice — sin cambiar el guión que ya probó funcionar.

---

## LEGO 22 — Público Objetivo Nuevo

**Bloques:** 📦 Material + 📝 **Script adaptado** + 🎵 Música + 🎬 Stock + 🪝 **Hook adaptado** + 🎯 CTA + 📐 Formato + 👥 **Público nuevo**
**Qué cambia:** El avatar al que se le habla. El script y el hook se adaptan a ese nuevo perfil.
**Qué hace Frank:** Identifica el nuevo avatar desde el análisis psicológico. Adapta el hook y el script completo al lenguaje, situaciones y tono de ese perfil. El ángulo ganador y el mecanismo se conservan.

**Lógica:** El mismo dolor puede vivirse desde perfiles diferentes. Esta variación lleva el mismo ángulo ganador a un nuevo segmento de audiencia que comparte el dolor pero lo experimenta en un contexto diferente.

**Cuándo usarlo:** Cuando el anuncio original está saturando su público principal y se quiere expandir a nuevos segmentos sin crear un nuevo ángulo desde cero. Cuando hay indicios de que otros perfiles responden al mismo dolor pero el copy no les habla directamente.

---

## LEGO 23 — Público Objetivo + Formato Nuevos

**Bloques:** 📦 Material + 📝 **Script adaptado** + 🎵 Música + 🎬 Stock + 🪝 **Hook adaptado** + 🎯 CTA + 📐 **Formato nuevo** + 👥 **Público nuevo**
**Qué cambia:** El avatar y el estilo de narración.
**Qué hace Frank:** Identifica el nuevo avatar. Adapta el script y el hook a ese perfil. Elige el formato que mejor conecte con ese tipo de público. Entrega en 3 bloques.

**Lógica:** Cada segmento de audiencia consume contenido de formas diferentes. Los jóvenes responden mejor a formatos selfie o POV; los líderes de ministerio responden mejor a formatos de conferencia o podcast. Esta combinación asegura que el contenido y el empaque estén calibrados al nuevo público.

**Cuándo usarlo:** Cuando se expande a un nuevo segmento de audiencia que no solo tiene un lenguaje diferente sino también hábitos de consumo de contenido diferentes. Es la variación más completa para conquistar un nuevo público sin perder el ángulo ganador.

---

## LEGO 24 — CTA Nuevo + Público Objetivo

**Bloques:** 📦 Material + 📝 **Script adaptado** + 🎵 Música + 🎬 Stock + 🪝 **Hook adaptado** + 🎯 **CTA nuevo** + 📐 Formato + 👥 **Público nuevo**
**Qué cambia:** El avatar, el hook, el script adaptado y el objetivo del cierre.
**Qué hace Frank:** Identifica el nuevo avatar. Adapta el hook y el script a ese perfil. Elige el objetivo de CTA más efectivo para ese segmento específico. Entrega en 3 bloques.

**Lógica:** Diferentes perfiles de avatar responden a diferentes tipos de cierre. Una mamá con hijos puede responder mejor a un CTA de regalo extra; un líder de célula puede responder mejor a un CTA de prueba social que valide que otros líderes ya lo usan. Esta variación adapta tanto el mensaje como la llamada a la acción al nuevo público.

**Cuándo usarlo:** Cuando se tiene claridad de que el nuevo avatar no solo necesita un lenguaje diferente sino también un tipo de motivación diferente para actuar. Es la variación más quirúrgica para conquistar un nuevo segmento con el cierre más adecuado para ese perfil.
